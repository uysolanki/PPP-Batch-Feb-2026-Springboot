interface FlyingBird {
    void fly();
}

interface RunningBird {
    void fly();
}


class Eagle implements FlyingBird, RunningBird {

    @Override
    public void fly() {
        System.out.println("Eagle is flying");
    }
}


Because both methods are identical, Java treats them as one single method.
There is no ambiguity.

Java checks only:
return type ✅
method name ✅
parameters  ✅


Since both interfaces declare:
void fly();
They are considered the same contract.
So one implementation satisfies both.

interface FlyingBird {
    default void fly() {
        System.out.println("FlyingBird fly");
    }
}

interface RunningBird {
    default void fly() {
        System.out.println("RunningBird fly");
    }
}


class Eagle implements FlyingBird, RunningBird 
{
	@Override
    public void fly() {
